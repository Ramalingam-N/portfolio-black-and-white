# Ramalingam N — Personal Portfolio

This repository contains the source code for my professional portfolio website. It is engineered to reflect a premium, minimalist design aesthetic, focusing on high performance, clean architecture, and responsive fluid layouts.

🌐 **Live Demo:** [ramalingam-n.github.io/portfolio](https://www.google.com/search?q=https://ramalingam-n.github.io/portfolio)

## 🏗️ Architecture & Tech Stack

This project was built entirely from scratch with a strict **zero-dependency** philosophy to ensure maximum performance and a perfect Lighthouse score.

* **HTML5:** Semantic, accessible markup with inline SVGs (no heavy icon fonts).
* **CSS3:** Built on a strict 8px spacing system using modern CSS Grid, Flexbox, custom properties (variables), and glassmorphism effects.
* **Vanilla JavaScript (ES6+):** Utilizes native `IntersectionObserver` for buttery-smooth scroll reveal animations, completely eliminating the need for heavy third-party libraries like AOS or jQuery.
* **Typography:** Premium pairings using Google Fonts (*Inter* for high-legibility body text, *Space Grotesk* for technical, crisp headings).

## ✨ Key Features

* **Engineered Design System:** Uses a unified dark-theme color palette and a strict 8px baseline grid to maintain visual rhythm and spacing consistency.
* **Native Scroll Reveals:** Custom-built, lightweight JavaScript observer handles all entry animations without blocking the main thread.
* **Zero Bloat:** No external CSS frameworks (like Bootstrap/Tailwind) or heavy JS libraries.
* **Flawlessly Responsive:** Mobile-first media queries ensure indistinguishable quality across 375px, 768px, and 1440px+ viewports.
* **Project Showcase:** Dedicated sections highlighting full-stack Java applications, API tools, and Chrome Extensions.

## 🚀 Local Development

To run or modify this project locally:

**1. Clone the repository:**
`git clone https://github.com/Ramalingam-N/portfolio.git`

**2. Navigate to the directory:**
`cd portfolio`

**3. Preview:**
Simply open `index.html` in your preferred browser. No build steps, bundlers, or package managers are required.

## 📁 Directory Structure

* `/css/style.css` — Core styling, variables, and responsive layouts
* `/js/script.js` — Vanilla JS for IntersectionObserver and nav logic
* `/images/` — Optimized image assets and favicons
* `/files/` — Downloadable assets (e.g., Resume PDF)
* `index.html` — Main semantic HTML structure
* `README.md` — Project documentation
